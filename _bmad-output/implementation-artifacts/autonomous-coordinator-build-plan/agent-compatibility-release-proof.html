Release Gates

  • Codex and ChatGPT surfaces are represented without embedding product-specific assumptions in the coordinator core.
  • Callable execution requires explicit discovery, qualification, authorization, and adapter support; otherwise the surface is handoff-only or rejected.
  • Public and private fallbacks independently qualify, and failure remains local to dependent slices.
  • Private plugin source remains immutable during project execution; project-specific behavior resides in project memory.
  • Credentials are referenced, not persisted. PHI and unknown-PHI projects use the restrictive synthetic/local policy.
  • Agent output requires redaction, schema validation, freshness, provenance, and memory admission.
  • Mandatory supervision cannot be bypassed through agent delegation.
