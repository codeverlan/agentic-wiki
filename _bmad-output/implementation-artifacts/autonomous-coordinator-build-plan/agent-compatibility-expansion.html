ChatGPT, Codex, Public Agent, and Private Agent Compatibility Expansion

This is a flat extension queue for the completed autonomous coordinator release. It does not rewrite the completed 48-item release history.

Compatibility Model

The coordinator treats every external agent as a qualified capability, not as an interchangeable model. Codex may expose skills, plugins, MCP, apps, worker controls, browser, image, command, and computer-use surfaces. ChatGPT may expose apps, connectors, actions, remote MCP, public agents, personalized agents, or only a conversational handoff. Public agents begin untrusted; personalized private agents may be preferred by project policy but remain independently versioned and immutable.

SEO Decision Lab Example

Private agent reference: plugin://seo-decision-lab@personal/
  1. Discover the exact installed plugin version, its skill, and local MCP surface.
  2. Check authentication status without reading or persisting credential values.
  3. Prefer shortcut DataForSEO tools when they fit; use the generic documented request surface otherwise.
  4. Record market, language, domain, intent, request hash, usage metadata, and result provenance in project memory.
  5. If credentials are missing, block only SEO-dependent slices and continue other work.
  6. Admit SEO findings and implementation proposals through privacy, provenance, validation, and integration gates.

Non-Negotiable Boundaries

  • No provider equivalence assumption.
  • No credential or hidden prompt persistence.
  • No delegation around computer-use or other mandatory supervision.
  • No public or remote agent receives PHI under the strict local-only policy.
  • Agent results remain proposed evidence until admitted and validated.
  • Unavailable agents block only dependent work; alternatives and independent slices continue.

Completion

Compatibility is complete only when callable and handoff-only ChatGPT fixtures, Codex fixtures, public-agent fixtures, private-agent fixtures, and the SEO Decision Lab path pass qualification, privacy, restart, provenance, supervision, and end-to-end evidence gates at the integrated revision.
