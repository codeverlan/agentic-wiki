Status Lanes

Dashboards may show one combined project status, but the source data keeps these lanes distinct so users can tell where progress, blockers, and supervision needs came from.

Incident And PHI Monitoring

Dashboards may show incident status and PHI-aware monitoring reminders, but source data remains metadata-only and must omit PHI, credentials, tokens, passwords, raw secret values, and raw sensitive text.
