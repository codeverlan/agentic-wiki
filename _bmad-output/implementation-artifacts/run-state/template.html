Validation Repair

Failed implementation slices get at most two bounded self-repair attempts. After the second unsuccessful attempt, stop the affected slice, record evidence, preserve or revert only slice-owned changes as appropriate, and continue independent slices.

Slice ID Attempt Failing command Fix hypothesis Touched paths Rerun result Preserve/revert decision

Resume Instructions

  1. Read _bmad-output/specs/spec-agentic-wiki-continuous-codex-development/SPEC.md.
  2. Load _bmad-output/implementation-artifacts/authority-ledger/template.html and its matching JSON before broadening authority or unattended dispatch.
  3. Load _bmad-output/implementation-artifacts/slice-queue.json.
  4. Start with the first active slice in the queue.
  5. Run the listed validation before the next commit.
  6. Do not use computer-use or GUI-driving workflows without user supervision.
