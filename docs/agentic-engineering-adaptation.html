Agentic Engineering Adaptation

Evaluation-first slice execution, provider-neutral capability routing, and advisory decomposition for the autonomous coordinator.

Project Memory Records

RecordPurpose
Slice evaluation contractDefines capability checks, regression checks, baseline revision, results, dominant risk, and done condition before implementation.
Evaluation comparisonRecords newly passing checks, regressions, unchanged failures, final revision, and completion result.
Execution-tier decisionStates the minimum narrow, implementation, or frontier capability required without naming a provider.
Execution telemetryLinks agent qualification, attempts, resource-ledger entries, validation evidence, and outcome.

Coordinator Rules

  • Missing baseline or integrated evidence prevents evaluated completion.
  • A capability success cannot conceal a regression.
  • Security-critical and privacy-critical work routes directly to the strongest required capability tier.
  • Multiple dominant risks or weak verification produce split advice, not an elapsed-time stop.
  • Project-specific decisions remain in the project wiki and never mutate reusable plugin defaults.
