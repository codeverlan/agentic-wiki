Agent Development Coordinator Qualification

A separate deterministic acceptance harness for proving the installed plugin bundle and its coordinator contracts.

Qualification Layers

LayerEvidence
BundleManifest, required skills, source/cache file hashes, and source immutability.
SafetyComputer-use supervision, credential-artifact scan, and PHI synthetic-only enforcement.
OrchestrationSeven project archetypes, six workers, blocked-slice continuation, and malformed-report rejection.
AgentsPublic, private, callable, handoff-only, and restart-equivalent host behavior.
EngineeringRegression rejection and direct frontier routing for critical risks.
ReportsContent-addressed JSON and standalone semantic HTML.

Release Rule

Run qualification against the installed cache after plugin contract changes. A failed case blocks plugin release, but does not stop unrelated project work. Reports remain outside immutable plugin source.
