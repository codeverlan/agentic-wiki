External Source Relationship Memory

The Agentic Wiki stores external agents, plugins, skills, MCP servers, APIs, apps, connectors, services, datasets, documents, repositories, and websites as first-class project-memory entities.

Storage And Editing

Each entity has a stable ID, portable locator, publisher, discovered version, capabilities, optional immutable wiki source reference, and credential-free metadata. Updates append a checked revision with a previous-revision hash. Existing history is never rewritten. Optimistic revision checks prevent silent concurrent overwrite, and tampered revisions fail integrity verification.

Relationship revisions are also append-only and can carry evidence such as request hashes, review state, or source locators without credential values.

Understanding The Graph

The public API resolves current entities, lists revision history, returns outgoing neighbors and backlinks, finds directed paths, reports transitive impact, and explains a relationship chain in readable form. The standard graph index combines current external entities and relationships with canonical wiki links.

Wiki Boundary

Raw ingested files remain immutable. External catalog edits never rewrite canonical HTML. New canonical knowledge still follows source-backed draft, validation, and promotion.

The default relationship projection is written to .memwiki/index/external-memory.html as XSS-safe semantic HTML with embedded JSON-LD. Clinical workspaces require OperationContext; credential-bearing entity metadata or relationship evidence is rejected.
