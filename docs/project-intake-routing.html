Project Intake And Adaptive Routing

Executable, restart-safe project discovery and host-aware worker selection for the Agent Development Coordinator.

Authoritative Intake

One atomic state record drives semantic HTML and JSON projections for intent, specification, decisions, PHI posture, design, dependencies, overlay policy, readiness, and initial work. Revision checks prevent lost updates. Checkpoint hashes detect tampering while allowing deterministic projection repair after interruption.

Readiness

Implementation readiness fails closed for unresolved PHI status, missing product purpose, users, outcomes, scope, acceptance criteria, source authority, design authority, external dependency classification, contradictions, or material open questions.

Adaptive Routing

TierDefault intent
NarrowLowest compatible host model with low reasoning for bounded deterministic work.
ImplementationBalanced host model with medium reasoning for implementation and integration.
FrontierStrongest required capability with high reasoning for architecture, ambiguity, security, privacy, or evidence-backed escalation.

Project policy can prefer concrete routes observed in the current host profile. The plugin itself remains provider-neutral.
