Coordinator Operator Runbook

Preflight and Initialization

python ~/.codex/plugins/cache/personal/agent-development-coordinator/<version>/scripts/coordinator.py --project-root . preflight
python ~/.codex/plugins/cache/personal/agent-development-coordinator/<version>/scripts/coordinator.py --project-root . init --run-id <id> --max-workers 6
memwiki --workspace . coordinator status

Preflight detects BMAD versus lightweight storage and verifies that outputs remain project-local. Ask whether the project handles PHI before real execution.

Bounded Control Commands

memwiki --workspace . coordinator tick

memwiki --workspace . coordinator resume
memwiki --workspace . coordinator verify

The installed plugin helper also provides inspect, status, lease, admit-report, and recover. A real unattended runner should omit artificial tick limits and stop only at an explicit boundary or proven completion.

Blockers and Supervision

Record user-input, missing-expected capability, technical, policy, and supervision blockers with affected descendants. Continue all independent work. A resource that should exist but is unavailable blocks its slice and triggers notification. A useful resource that does not exist becomes a future advisory. The supervision queue remains chronological; safety, legal, irreversible, destructive, financial, publication, and authorization actions require supervision.

Recovery

  1. Verify journal, checkpoint, projection, and hashes.
  2. Acquire a newer fenced coordinator lease.
  3. Reconcile active assignments, worktrees, command receipts, and integrations.
  4. Never repeat an external effect marked started with an uncertain outcome; route it to supervision.
  5. Resume or requeue recoverable slices and continue independent work.

Troubleshooting

Stale writerReject its fencing token and preserve its report as rejected evidence.
Torn journal tailQuarantine only the incomplete final frame; immutable interior corruption requires intervention.
Dirty main checkoutPreserve it and use isolated worktrees; never destructively clean user changes.
Credential missingStop only the invocation-dependent slice and report the credential reference, never its value.
PHI policy violationDeny the operation, store a hash-only violation, and continue non-PHI-safe work.
Hard stops: explicit user stop, declared deadline/time boundary, usage or budget exhaustion, a global safety boundary, or verified completion. A phase boundary is never a hard stop.
